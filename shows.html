Owner code

Managing shows needs the owner code (OWNER_SECRET in Vercel). It is kept on this page only, never stored — retype it each visit. It stops a bandmate changing things by accident; it is not a login.

Every show

Any number of shows can be open at once, each with its own ballot, votes, set, practice tracker and rehearsal calendar. The home page opens whichever gig is next up. Mark a show finished once it has been played: it stays viewable, read-only. Nothing here deletes anything.

Start a new show

Copying from an earlier show brings its songs and settings (who votes, who plays, set size, warnings) — never its votes, practice marks or availability. Lyrics, tempos and tunings are shared by every show already.
