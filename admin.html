Owner code

The owner code (OWNER_SECRET in Vercel, or the old admin key if that is all that is set). Not stored anywhere — retype it each visit. It stops a bandmate changing the list by accident; it is not a login.

Add a song

A song that has been in an earlier show brings its length, energy, tags, lead, keys, lyrics, tempo and tuning with it — anything you leave blank here is filled from there.

Keys says how much the keyboard matters: Essential (the song does not work without it), Adds to it, or Not needed. Leave it on “not judged” until someone has actually decided — blank and “not needed” are different answers, and the learn page shows them differently.

Tuning is free text — type whatever you actually use. Leave it blank and the setlist treats the song as E standard. The generated running order flags every point where the tuning changes from the song before it, so you can see how many guitar swaps the order forces on you.

Tags steer the running order: opener / closer pin it to the ends, heavy clusters it at the peak, ballad or dedication places it after the peak lift follows the ballad, dip sits a third in. Put - in Tags to strip a song's built-in tags — useful if you don't want something pinned to the closing slot.

Bulk add

One per line: Song | Artist | Lead | Length | Energy | Section | tags | tuning. Only song and artist are required.

Show settings

Everything that makes this show this show. Names are the authority for who votes and who plays: taking a name off stops that person counting but deletes nothing, so putting it back restores them.

Start a new show

A new show gets its own ballot, votes, set, learning and rehearsal calendar. Copying from an earlier show brings its songs and settings, never its votes. Lyrics, tempos and tunings are shared by every show already.
